\section{问题一：单点往返运输能力与货箱组批}

\subsection{最大安全载荷的求解}

单服务区往返架次为 O01$\to S_i\to$O01，去程携带载荷 $q$，返程空载。该架次总能耗为
\begin{equation}
	E_i^{\mathrm{RT}}(q)=E_{g,\mathrm{O01}\to i}(q)+E_{g,i\to \mathrm{O01}}(0).
\end{equation}
由于 $E_i^{\mathrm{RT}}(q)$ 关于 $q$ 单调递增，最大安全载荷即为满足 $E_i^{\mathrm{RT}}(q)\le(1-\rho_g)E_g^{\mathrm{use}}$ 的最大 $q$，可用二分法精确求解。计算结果如表~\ref{tab:q1-maxpayload}所示。

结果表明，A（最大载荷 25\,kg）与 B（最大载荷 30\,kg）两种机型因载荷小、空载质量轻、航程长，除 S008 对 B 型因地形爬升略有限制（$28.70$\,kg）外，在全部服务区均不被能量约束限制；而 C 型重载机满载航程仅 12\,km、可用能量 8\,kWh，在距离远、地形爬升大的 5 个服务区（S002、S003、S004、S008、S012）上最大安全载荷显著低于其 80\,kg 的额定载质量，其中 S008（距 O01 约 8.1\,km）降至 58.57\,kg，体现出能量余量对重载机型运输能力的显著制约。

\subsection{货箱组批与优化}

在每个服务区内部，货箱不可拆分、不得跨服务区组批，需满足质量不超过最大安全载荷、体积不超过机型可用装载体积。由于最大安全载荷已由上述二分法求为常数上界，把它并进载质量约束后，组批问题不再含非线性项。同一服务区内的货箱只按（质量，体积）取值区分，取值相同的货箱在质量约束、体积约束、能耗与作业时间上完全等价，故先把货箱归并为\textbf{同质类}，再枚举“一个架次可以装哪几类各几件”的全部\textbf{架次模式}，最后在“各类货箱各取多少件”的\textbf{多重集状态}上做动态规划。状态为各类已运件数的多元组，每区货箱不超过 4 个同质类且每类件数有限，故状态空间不超过 $324$ 个，逐区求解耗时在毫秒量级，且给出的是该区在该机型下的\textbf{全局最优}组批。

为保证这一结论不依赖单一实现，本文用\textbf{两条独立路径}复核（结果见 \texttt{results/\allowbreak q1\_\allowbreak ilp\_\allowbreak gap.csv}）：其一为\textbf{指派式 0-1 整数规划}（变量为“箱 $i$ 放入架次 $j$”与“架次 $j$ 是否启用”，用 $y_{ij}\le u_j$、$u_j\le u_{j-1}$ 打破架次编号的置换对称），以最小化架次；其二为\textbf{集合划分整数规划}（先子集枚举出全部架次模式作为列，求恰好 $k$ 架次下的最小能耗），以最小化能耗。两条路径与动态规划在全部 $15\times3=45$ 个“服务区$\times$机型”组合上\textbf{逐行一致}；作为对照，若沿用降序首次适应（FFD）装箱，则在 45 个组合中有 2 个非最优（S007 与 S008 的 B 型，架次由 2 增至 3），对应能耗分别由 $3.427$ / $5.751$\,kWh 升至 $4.862$ / $8.165$\,kWh。按全部 45 个组合的总能耗计，FFD 为 $261.827$\,kWh、动态规划为 $254.902$\,kWh，\textbf{冗余 $2.72\%$}（分母取精确解）；若按后文推荐的 18 架次混合方案计，FFD 为 $64.364$\,kWh、动态规划为 $63.181$\,kWh，冗余 $1.87\%$——值得注意的是此时\textbf{两者的架次数完全相同（均为 18）}，说明该冗余来自\textbf{货箱划分}（同样的架次数下每个架次装哪几个箱不同，进而改变各架次的载荷分布与能耗），而不是架次数差异。

由表可见三个指标存在明显的权衡：C 型以最少的架次（18）和最短的累计作业时间（9.40\,h）完成任务，但总能耗高于 B 型；B 型总能耗最低（68.470\,kWh）但架次增至 35、作业时间增至 15.47\,h；A 型在各指标上均劣于 B 型。据此本文推荐“大服务区用 C 型、小服务区用 B 型”的混合方案。选型与组批按\textbf{三级字典序}求解：
\begin{equation}
	\min_{\mathrm{lex}}\Big(\sum_{j} x_j,\ \ \sum_{j} E_j,\ \ \sum_{j} T_j\Big),
	\label{eq:q1-lex}
\end{equation}
即“单次荷载最大 $\Rightarrow$ 架次数最少”为第一优先级，总能耗次之，累计作业时间再次；式中 $x_j$ 表示架次 $j$ 是否启用，$E_j$、$T_j$ 为其能耗与作业时间。§5.4 的引理 1 将说明第三层其实不产生额外区分。按此解得：S001--S008 由 C 型承运（S001--S003 各村各需 2 架次，S004--S008 各 1 架次），S009--S015 由 B 型承运（各村 1 架次），共 18 架次、总能耗 63.180\,kWh、累计作业时间 9.173\,h——相对全 C 方案架次相同而能耗降低 $14.7\%$、时间缩短 $2.4\%$；相对全 B 方案架次减少 $48.6\%$、时间缩短 $40.7\%$ 而能耗还低 $7.7\%$，即在三个指标上同时不劣于两种单一机型方案。

进一步地，本文以架次上限为约束扫描出\textbf{帕累托前沿}（表~\ref{tab:q1-pareto}）。表中“方案”列只列出相对推荐行发生机型变更的服务区，未列出的服务区机型不变。可见前沿非常平坦：架次由 18 增至 23（$+27.8\%$）仅换来总能耗由 $63.180$ 降至 $62.687$\,kWh（$-0.78\%$），代价是累计作业时间由 9.173\,h 增至 11.457\,h（$+24.9\%$）。

这 $-0.78\%$ 的降耗有一个容易误读的机制，须予点明：架次由 18 增至 23 共 $+5$，恰等于 S002（$+2$）、S003（$+2$）、S008（$+1$）三个服务区的增量，即降耗的\textbf{唯一来源是这三个服务区由 C 型改由 B 型承运}，而不是把同一型号的架次拆得更碎。后者只会更费能——同型号内拆架次不改变总箱数，却要多付一次起降与交接的固定开销，例如 S002 的 C 型在 $k=2,\dots,8$ 时能耗由 $10.453$ 单调升至 $37.722$\,kWh。若把“架次多则能耗低”当成一般规律，就会得出与模型相反的结论。

这意味着在本题的能量参数下“多飞几趟以省电”几乎无效，架次数而非能耗才是运力规划的决定性指标，故取 18 架次方案为推荐方案。

\subsection{返航安全余量的影响}

返航安全余量 $\rho_g$ 直接影响可用能量 $(1-\rho_g)E_g^{\mathrm{use}}$，进而改变最大安全载荷与组批结果。图~\ref{fig:q1-sens}给出了三种机型平均最大安全载荷随 $\rho$ 的变化。

	\caption{返航安全余量对最大安全载荷的影响}

可见三型呈现三种不同的阶梯形态（同一条曲线亦见于图~\ref{fig:q1-payload}(b)）。A 型与 B 型在 $\rho$ 较小时是\textbf{平台}——$\rho\le0.20$ 时 A 型恒为 25.00\,kg、$\rho\le0.15$ 时 B 型恒为 30.00\,kg，说明此区间内二者的瓶颈是载质量上限而非能量，提高返航余量不损失运力。C 型则自始受能量约束，平均最大安全载荷由 $\rho=0.10$ 时的 78.68\,kg 单调降至 $\rho=0.40$ 时的 52.64\,kg（$\rho$ 每增大 10\% 平均下降约 8.7\,kg，与表~\ref{tab:sens}一致），且下降在 $\rho>0.30$ 后明显加速。

以总架次数为观测量对 $\rho$ 做二分定位，可得组批方案的\textbf{临界点}：$\rho=0.2283$ 时总架次由 18 跳至 19，此后 $0.2686$、$0.3345$、$0.3415$ 依次跳至 20、22、25 架次；当 $\rho$ 超过 $0.3513$ 时方案整体失效——此时最不利服务区 S008 对三种机型均已不可达。分机型看，S008 的作业可行性上界为 A 型 $0.2992$、C 型 $0.3510$、B 型 $0.3513$，即\textbf{率先失效的是航程最短、能量最小的 A 型}（$\rho>0.2992$ 后 A 型空载亦无法往返 S008），随后才是 C 型与 B 型。这意味着提高安全余量对运力的压缩不是均匀的：它先剥夺小型机的可达性、再压缩重载机的有效载荷，二者叠加使架次数阶梯式上升，安全性与运输效率需要在上述临界点之间权衡。

\subsection{解耦性与全局最优性}

本节给出两条引理，说明 §5.2 按“服务区$\times$机型”逐格求解为何等价于全局最优，以及式~\eqref{eq:q1-lex} 中作为第三层的作业时间为何不产生额外区分。两条引理在\texttt{code/q1.py} 中都有同名的运行时数值断言作为支撑。

\textbf{引理 1（作业时间对架次数严格仿射）}。由式~\eqref{eq:energy-margin} 所在的物理模型可知，航段飞行时间只由爬升、巡航、下降三段构成，\textbf{不含载荷项}，故一个架次的作业时间为
\begin{equation}
	T_j=\big[\mathrm{prep}+\mathrm{hand}_{\mathrm{base}}+t_{\mathrm{go}}+t_{\mathrm{back}}\big]+\big[\mathrm{load}+\mathrm{hand}\big]\,n_j \;=\; A+b\,n_j,
	\label{eq:q1-affine}
\end{equation}
其中 $n_j$ 为该架次承运的货箱数，$t_{\mathrm{go}}$、$t_{\mathrm{back}}$ 为去程与返程航段的时间。对某服务区该机型的全部架次求和时 $\sum_j n_j=N$ 即该区货箱总数，是定值，于是
\begin{equation}
	T_{\mathrm{total}}(k)=A\,k+B,\qquad B=b\,N,
	\label{eq:q1-affine-total}
\end{equation}
\textbf{与货箱如何分配到各架次无关}。因此架次最少的解自动就是累计作业时间最短的解，字典序第三层不产生额外区分——这正是式~\eqref{eq:q1-lex} 中第三项可以写在末位而不改变最优解的原因。

这一性质在代码侧有运行时断言：\texttt{code/q1.py} 的 \texttt{time\_affine\_coeffs()} 给出式~\eqref{eq:q1-affine-total} 的 $A$、$B$，\texttt{assert\_time\_affine()} 则对全部 45 个（服务区$\times$机型）组合各取 2 种不同的货箱划分，把逐个架次累加的真实时间与 $Ak+B$ 逐一比对，实测最大偏差为 $1.8\times10^{-12}$\,s。读者也可在结果表上复核：\texttt{results/q1\_pareto\_area.csv} 中架次档不少于 3 的 38 个组合，其“架次--作业时间”最小二乘斜率\textbf{全部为正}，取值区间为 $1009.55$\,s/架次（S011$\cdot$B）至 $2143.34$\,s/架次（S003$\cdot$A）。此处有一处口径需说明：该表只保留 0.1\,s 精度，故直接读表会看到不超过 $0.049$\,s 的表观残差，那是\textbf{舍入}而非模型残差，引用时应以全精度断言值为准。作为直观例子，S002 的 C 型在 $k=2,\dots,8$ 时作业时间为 $3965.6\to14278.5$\,s，逐档增量恒为 $1718.83$\,s。

\textbf{引理 2（逐区解耦 $\Rightarrow$ 逐区字典序最优即全局字典序最优）}。问题一要求货箱不得跨服务区组批，且不涉及实体无人机与共享电池的调度，故一个服务区的决策（选型、架次数、货箱如何分批）既不改变其他服务区的可行域，也不改变其目标值；而式~\eqref{eq:q1-lex} 的三个目标都是各服务区对应量之和。于是把各区各自的字典序最优解拼接起来，得到的必是全局字典序最优解。反过来说，任何全局最优解限制在单个服务区上也不会劣于该区的字典序最优解——否则把该区替换为其字典序最优解即可改进全局目标，与全局最优矛盾。这正是本文按“服务区$\times$机型”逐格求解、而不做跨区联合枚举的正当性依据。需要指出的是，这条引理依赖“不得跨区组批”这一题面约束：一旦允许跨区拼箱，各区的可行域立刻相互耦合，逐区解耦不再成立。

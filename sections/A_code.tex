\section{求解代码清单}

本文全部求解代码位于项目 \texttt{code/} 目录，每个问题一个独立脚本，按序运行即可复现全文结果。所有代码均为 Python 3 实现，依赖标准科学计算与绘图库（numpy、pandas、matplotlib、seaborn、networkx，以及用于整数规划与二分求解的 scipy）。问题一、三、四的求解是确定性的（精确动态规划、整数规划与完全枚举），不含任何随机成分；问题二的大邻域自适应搜索是启发式，其随机流由脚本内的固定种子 \texttt{ALNS\_SEED} 初始化，故同一份代码重复运行的结果逐位一致，但该结果\textbf{依赖这一固定种子}——换种子会得到不同的解，本文不做多种子对照实验，也不据此声称该解已最优（其质量由 §6.3 的两层小规模精确解标定）。

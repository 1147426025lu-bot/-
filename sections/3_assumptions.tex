\section{模型假设与符号说明}

\subsection{模型假设}
为在保证问题本质不丢失的前提下建立可计算的模型，本文做出以下假设。每条假设后括注其\textbf{适用的问次}：标注「问题一--四」者为四问共享的公共物理口径（第 \ref{sec:physics} 节），只标注个别问次者仅在该问生效，不向其他问外推。

\begin{itemize}
	\item \textbf{假设 1（直线航段，问题一--四）：}任意两个任务节点之间采用两点间的水平直线作为运输航段，水平巡航距离按局部平面投影（WGS84）计算。
	\item \textbf{假设 2（巡航海拔，问题一--四）：}计划巡航海拔取该航段所经过 DEM 像元的最高地面高程以上 50\,m，且不低于起终点作业高度；爬升与下降为竖直运动，水平巡航为定高飞行。
	\item \textbf{假设 3（能耗口径，问题一--四）：}水平巡航能耗由等效航程反推（$E^{\mathrm{hor}}=E^{\mathrm{use}}\cdot d/L_g(q)$），爬升附加能耗取重力势能除以爬升能耗效率；下降不单独计能耗（效率为 0）。
	\item \textbf{假设 4（理想环境，问题一--四）：}忽略风、雨、能见度等气象因素对飞行时间与能耗的影响；无人机起降、悬停、交接过程稳定可靠。
	\item \textbf{假设 5（充电模型，问题二--四）：}电池与能源组件统一采用题给两阶段等效充电模型，多块电池可并行充电，同一资源占用与充电时段不重叠。问题一按单架次的往返能力评估，不涉及跨架次的电池周转，故不受本条约束。
	\item \textbf{假设 6（中继共享，问题三）：}一架中继无人机可同时为多架位于其覆盖范围内的运输无人机提供通信保障，但不允许多跳中继转发。问题一、二不建模通信，问题四只按数量核算中继资源需求、不复算链路，故本条仅作用于问题三。
	\item \textbf{假设 7（通信判定，问题三）：}通信链路按自由空间传播损耗加地形遮挡附加损耗进行链路预算，双向取较小门限判定链路可用性。适用范围同假设 6。
	\item \textbf{假设 8（机间间隔，问题二--四）：}不建模运输无人机之间的最小水平安全间隔与高度层分配，机间冲突只在「同一共享资源不被两个任务同时占用」的意义上被排除（占用与冲突的检查见 \ref{sec:occupancy}~节），不建模机间避让、尾流与由此产生的人为延误。问题一为单机往返、不涉及机队调度，故不受本条约束。
	\item \textbf{假设 9（运行合规，问题一--四）：}本文只求解运输与通信的调度问题，不建模空域分类、飞行活动审批与飞行计划报批等运行管理程序\cite{guowuyuan2023feixing}，也不建模无人驾驶航空器系统自身的适航与产品安全要求\cite{samr2023uavsafety}。二者均在本模型口径之外，故本文的任何结果都\textbf{不得}读作已满足上述法规与标准。
\end{itemize}

\subsection{符号说明}
本文涉及无人驾驶航空器系统的术语以国家标准《无人驾驶航空器系统术语》\cite{samr2019uavterminology}为参照；为免歧义，下表对本文使用的每个符号另行逐项定义，符号的含义与单位以本表为准。本文使用的主要符号及其含义如表~\ref{tab:symbols}--\ref{tab:symbols-c}所示，按「公共物理量与通信链路、问题一与问题二、问题三与问题四」分列三表。每行给出\textbf{符号、含义与单位}；「单位」一栏的「---」表示该量无量纲，或本身是下标、集合与二元变量而不带单位。

同一字母在不同问次下含义不同的三处，均在其所辖的表内写明适用范围、不再跨表混用：$k$（架次数与架次下标）、$K$（问题二为架次数上限、问题四为任务组数）、$R$（问题三为中继无人机的下标、问题四为不带下标的资源规模）。另有六处记号已作区分以免一符多义，改动同时落在正文里：重力加速度记 $g_0$ 以避开机型编号 $g$（式~\eqref{eq:leg-energy}）；地形遮挡变量记 $\beta_{ab}$ 以避开引理 1 的时间斜率 $b_g$（式~\eqref{eq:pathloss}）；时间积分的采样点下标记 $m$ 以避开任务节点编号 $i,j$；失效区间下标记 $\ell$ 以避开节点编号 $j$（式~\eqref{eq:setcover}）；任务组编号记 $\gamma$ 以避开机型编号 $g$（式~\eqref{eq:q4-workload}）；big-$M$ 界中的充电时长不引入下标，以避开货箱编号 $c$。

\subsection{模型参数与取值来源}
\label{sec:param-source}

本文沿用题目给定的 A/B/C 三型运输无人机划分。作为背景，民用无人驾驶航空器的系统分类及分级另有国家标准\cite{samr2018uavclassification}；本文不改动题给的三型划分，也不把题给的三型参数映射到该标准的分级上。

建模所用参数分两类，两类分别列于表~\ref{tab:param-given} 与表~\ref{tab:param-calib}。
一类直接取自题面与配套数据文件，\textbf{改动其中任何一个都等于改题}，本文不做任何平滑、
取整或量级化处理；另一类在题面留白处由本文标定，属算法与离散化设计，其取值本身不是题面结论。
两类表共用四栏，其中两栏的写法规矩须先说明：

\textbf{「定义位置」栏。}给的是源码文件与行号，而不是「见某某节」这类指向。
定这条规矩是为了让参数的出处可被机械核对：读表的人不必通读全文，只需打开所指文件行，
即可确认论文写的取值与代码真正使用的取值一致。反之，凡在 \texttt{code/} 中\textbf{指认不出}
定义位置的量，本文一律不写进这两张表——宁可少列，也不列一个只有作者才知道来历的数。

\textbf{「敏感性」栏。}记录该参数在第~\ref{sec:validation}~章的哪一处被扰动过，记「\texttt{---}」
者表示本文\textbf{未}对其做扰动检验。这一栏刻意与前三栏并列，是为了把「检验过什么」与
「没检验什么」一并交底：只报前者、把后者留白，读者会默认全都检验过，那是另一种形式的失真。
按此栏可以看出，本文的扰动检验集中在返航余量 $\rho$（表~\ref{tab:sens}）、
能量标度 $\kappa$（图~\ref{fig:q1-sens2d}）与 DEM 离散化（\ref{sec:dem-caliber} 节）三处，
其余参数取固定值；这些固定值对结论的影响范围，见第~\ref{sec:validation}~章与 \ref{sec:evaluation} 节的局限说明。

「原始数据本身长什么样」。表内每一行的「规模」栏不是从数据说明里抄的，而是由脚本在运行时
\textbf{逐个打开文件量出 shape} 得到的，故数据一换、表就跟着变，不会出现「论文写着 80 箱、

点位、水体、水系与道路四组图层，本文的求解与绘图均未读取；把它写进表里并注明「未进入
求解链路」，而不是从表里悄悄省掉——省掉会让读者以为数据集只有前面六份，把「没用」读成
「没有」。本表与上面两张参数表合起来，构成全文的输入交底：数据有哪些、字段是什么、规模
多大，以及每个建模参数取自何处、是否经过扰动检验。

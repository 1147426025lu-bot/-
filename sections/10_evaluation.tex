\section{模型的评价与推广}
\label{sec:evaluation}

\subsection{模型的优点}

\begin{itemize}
	\item \textbf{物理口径统一、可复现：}四个问题共享同一套地形净空、等效航程、能耗、充电与通信链路模型，单位、对象编号与计算口径一致，全部计算可由独立 Python 脚本复现，数据与结论可追溯。
	\item \textbf{充分刻画地形与通信约束：}巡航海拔由航段所经过的 DEM 像元最高高程确定，通信状态同时考虑视线遮挡与双向链路预算，较真实地反映了山区环境对运输与通信的双重制约；通信\textbf{中断时间}被写成必须归零的硬指标而非加权项（连续性是须为 $1$ 的状态，归零的是中断），与题面把「连续通信」列为约束的表述一致。
	\item \textbf{方法选择与问题结构匹配，并以精确解为标尺：}问题一用同质类多重集动态规划在\textbf{允许混用机型}的可行域上求全局最优，并经指派式、集合划分与混用机型三条独立整数规划路径逐行复核（$45/45$、$44/44$，以及混用机型路径 $15$ 区\textbf{全部一致}）；问题二用大邻域自适应搜索（ALNS）配 $\varepsilon$-约束扫描，再用两层小规模精确解标定最优性间隙；问题三用集合覆盖整数规划把悬停高度升为决策变量，并让运输开始时刻进入同一优化问题；问题四用受限增长串完全枚举，枚举结果即全局最优，另以组列集合划分整数规划复核。四问的计算量均在合理时间内完成。
	\item \textbf{揭示多目标权衡：}通过架次数上限—能耗—完成时间的非支配前沿、返航余量—电池能量的二维扰动、通信中断归零的完成时刻代价、以及分区组数—资源规模—均衡度三组定量对照，量化了及时性—能耗—架次、安全性—运力、通信连续性—任务时长、均衡—资源之间的权衡关系，为决策提供了方向性依据。
\end{itemize}

\subsection{模型的缺点}

我们如实列出尚未消除的残留问题，不以「已用高级算法」掩盖其局限。

\begin{itemize}
	\item \textbf{启发式的全局最优性未经证明：}问题二的 ALNS 仍是启发式算法。虽然两层小规模精确验证给出了 Layer A 三个算例间隙全为 $0$、Layer B1/B1$'$ 的最优性证书，但这些算例只含 3 个服务区、8 架无人机对至多 9 个架次，\textbf{机队资源竞争几乎不存在}，故它验证的是组批、能耗、路径与时序逻辑的正确性，\textbf{不能}外推为「全局资源拥塞情形下已证最优」。
	\item \textbf{自由指派层的整数规划间隙很大：}Layer B2 放开了无人机与共享电池的物理指派，求解 90\,s 后超时且最优性间隙仍有 $65.77\%$，其可行上界虽然比贪心排程短 $5.58\%$，但该上界\textbf{违反 9 项硬时限}，故只能作为搜索方向上的佐证，\textbf{不构成最优性证明}；同层 B1 的最优解虽已证最优，但该解本身违反 8 项硬时限，故同样只作下界参考而不作为可行方案。
	\item \textbf{消融实验暴露了一处搜索质量问题：}放开架次数上限的两行（④、⑤）解空间严格更大，四项指标却都不如架次受限的 ③：③ 为 26 架次、$73.526$\,kWh、完成时间 $7\,235.7$\,s、加权时延 $0$，而 ④ 升到 32 架次 / $89.394$\,kWh / $9\,447.7$\,s / 时延 $51\,008$，⑤ 为 28 架次 / $82.042$\,kWh / $7\,376.4$\,s / 时延 $7\,245$。原因是固定迭代预算下，放开上限后搜索更容易停在「多架次、长完工」的局部解。我们在 6.3 节如实报告该现象，未将其粉饰为「全量搜索更优」；同时如实报告 ⑤ 相对 ④ 的四项全面改进，说明三层移植本身有效，只是不足以抵消放开上限带来的退化。
	\item \textbf{换站修复产生的新悬停站未经连续精化：}问题三的第三级修复动作要给某区间「改换一个届时真正在位」的悬停站，做法是直接从候选表中取站，该站\textbf{未经过} \texttt{refine\_station} 的 $({\rm lon},{\rm lat},h)$ 坐标下降精化。精化会改变站址、进而改变去程时长与建链时刻，因此不能在排班完成后再补做。这些站的有效性由覆盖矩阵的全密度复核保证，但接入裕量不如精化过的站；最终方案一律以 $\Delta t=1$\,s 的逐时刻审计为准。
	\item \textbf{分区方案在给定库存下均不可行，且成因是联合约束而非任何单类短缺：}问题四的结论是两类分区在现有库存下都不可行（2047 / $86\,526$ 个分区中库存可行分区数均为 $\mathbf{0}$）。仅凭「不可行」二字容易把成因误读成「某类资源不够」，我们据全部分区上的最小需求把它讲清楚：$K=2$ 与 $K=3$ 下\textbf{八类资源的最小缺口全部为 $0$}，即单独针对任何一类，都存在一个不超库存的分区——A、B、C 型运输无人机与三类共享电池的最小需求都正好等于库存，中继无人机为 $2$（等于库存 $2$），余量同样是 $0$。既然逐类看处处有解、整体却一个可行分区都没有，不可行性只能来自\textbf{联合约束}：不存在任何一个分区能同时取到八类资源各自的最小值，否则它本身就是一个可行分区，与枚举结果矛盾。「逐类有余量」与「整体不可行」并存，说明这类否定性结论只能靠完全枚举得到，单个候选分区上的核算给不出。与之一并说明的是中继机的临界程度：题目禁止跨组调配，故每个含失效区间所在服务区的组都至少要占 1 架中继无人机；12 个原子单元中只有 U06（S006）不含失效区间，故含失效区间的组数下界为 $K-1$，$K=3$ 时恰为 $2$、等于库存，\textbf{余量为 $0$}——这是本算例中中继机队离临界最近的一处。补配时应据此预留，但它\textbf{本身不构成}结构性短缺。推荐分区（按式~\eqref{eq:q4-lex} 先 $R$ 最小、再 $CV_W$ 最小选出）上的缺口是「省资源＋求均衡」这一目标的代价：$K=2$ 缺 B 型运输无人机 1 架、中继无人机 1 架，合计 $2$ 件；$K=3$ 缺 A 型运输无人机 1 架、B 型运输无人机 1 架、A 型共享电池 1 组、中继无人机 2 架，合计 $5$ 件。这些缺口\textbf{每一项都可以单独靠换一个分区消去}，但\textbf{不能同时消去}。因此我们给出的是补配清单而非可行分区，并明确说明补配件数取决于选哪个分区、而「必须补配」这件事与选哪个分区无关。
	\item \textbf{遮挡判定未含电磁净空与绕射：}我们的视线遮挡判据是几何式的「连线是否穿过地形」——采样加 1\,mm 容差，遮挡附加损耗按题给的固定值计入，全文\textbf{未}建模第一菲涅尔区净空、绕射与多径。因此判定实际比物理更宽松：掩体边缘附近的链路可能被我们判为可用而实际不可用。我们没有为这一项预留额外的几何裕量（否则就是让判定与实现脱节），故本模型给出的覆盖与直连占比应理解为\textbf{偏乐观的上界}；若要收紧，须在链路模型里真正加入菲涅尔半径判据并重算；这一点我们没有做。
	\item \textbf{未建模机间间隔与避撞：}\ref{sec:occupancy}~节的占用冲突检查只保证「同一资源不被两个任务同时占用」，它\textbf{不是}机间最小安全间隔——不同无人机在同一时刻、同一空域内的相互避让全文未建模，也未做高度层分配。在本算例的规模下（同一时刻至多 2 架中继机、运输架次按资源链错开）没有出现需要避让的观测，但这只是本算例的观测，\textbf{不构成}一般情形下的安全保证。
	\item \textbf{部分参数为简化假设：}未考虑风场、雨雾、起降排队、充电桩数量等实际因素对飞行与周转的影响。
\end{itemize}

\subsection{模型的改进}

\begin{itemize}
	\item 对问题二可延长迭代预算或采用多起点并行搜索，以缓解上述 ④ 的搜索质量问题；对 Layer B2 可加入割平面或列生成以缩小 $65.77\%$ 的间隙，把自由指派层的最优性也纳入验证范围。
	\item 对问题三可把换站后的新站补做连续精化，但精化必须与排班\textbf{联合迭代}而非事后追加，否则站址变化会使已排定的建链时刻失效。
	\item 对问题四可引入跨组资源共享协议（如资源的时分复用或动态调配许可），以降低「不得跨组调配」带来的机队放大效应；也可在目标中显式加入工作量均衡项，以避免多分组反而更不均衡的现象。
	\item 可建立充电桩数量约束下的多队列充电仿真，细化电池周转模型。
\end{itemize}

\subsection{模型的推广}

我们的“地形感知飞行＋能量余量＋通信链路”联合框架，可推广至其他山区/海岛/灾区的无人机物流、电力巡检、应急通信中继等场景；任务分区与资源配置核算方法也可用于多作战单元、多救援分队的兵力/资源编配决策。
